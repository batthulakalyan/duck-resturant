# DUCK Restaurant Website

A responsive restaurant website built with plain HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract `duck-restaurant.zip`.
2. Open the `duck-restaurant` folder.
3. Double-click `index.html` or open it with a browser.

For a local development server, you can use VS Code Live Server.

## Features
- Responsive restaurant landing page
- Menu category filters
- Add-to-cart, quantity controls, remove items and totals
- Cart saved in browser localStorage
- Demo checkout form
- Reservation form validation
- Offers, gallery, contact section

## Important demo limitations
This is a **frontend-only demo**. Cart and form interactions run in the browser. Reservation requests are not sent to a restaurant, checkout does not create a real order, and no payment is processed. To operate as a real business, connect a backend API/database, secure admin authentication, order processing, and a payment provider.

## Customize before publishing
- Replace placeholder address, phone, email and hours in `index.html`.
- Update sample prices and menu items in `script.js`.
- Replace demo food photos with licensed images of your actual dishes.
- Verify all business information and offers.
- Connect forms and ordering to a secure backend before accepting real orders.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — menu, filters, cart and demo forms
